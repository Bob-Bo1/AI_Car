# 接线图文件

- `AI小车_接线图.svg`、`AI小车_接线图_16比9.svg`：当前 V7 减少交叉版，1920×1080。器件图片内嵌，文字、导线、接点可编辑。
- `AI小车_接线图_1920x1080.png`、`AI小车_接线图_3840x2160.png`：视频用成品。
- `接线数据.json`：当前引脚和导线数据；`接线数据_交叉优化前.json`仅供生成器比较交叉数量。
- `生成16比9接线图.py`及`白底器件素材/`：重建所需源码和图片。生成器保留相对路径，直接在此目录运行即可生成 SVG。

图片等比例缩放，驱动板、电机和 OLED 在图中旋转 180 度以便走线。实心圆点表示连接，跨线弧表示不连接。器件图经已确认实物照片生成，细小纹理不用于加工。

主控：D2→IN1，D3→IN2，D6→IN3，D7→IN4；D4→OLED SDA，D5→OLED SCL，3V3→OLED VCC。

电源：电池正极→开关左外脚，开关中脚→升压 VIN；开关右外脚和两边金属固定脚不接。升压已设为 5V，VOUT 分别接主控 5V 和驱动正极。电池负极、升压两组 GND、主控 GND、驱动负极共地。电机分别接驱动 A/B 输出，两根电机线都不接公共地。USB 供电调试前先断开外部 5V。
