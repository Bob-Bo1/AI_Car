# 接线图

`AI小车_接线图.svg` 是当前 V7 可编辑源文件，器件图片全部内嵌。使用 Inkscape、Illustrator 等 SVG 编辑器可直接修改文字、接点和导线，无需额外器件图片。

提供 1920×1080 和 3840×2160 PNG，适合横屏视频。`接线数据.json` 保存当前引脚和网络数据。

器件只等比例缩放和旋转；实心圆点表示连接，跨线弧表示不连接。主控 D2/D3/D6/D7 分别接驱动 IN1/IN2/IN3/IN4，D4/D5 分别接 OLED SDA/SCL，3V3 接 OLED VCC。

电池正极经开关左外脚与中脚接升压 VIN；右外脚及固定脚不接线。升压已设 5V，分别接主控 5V 和驱动正极。各 GND 共地。电机两根线接对应 A/B 输出，不接公共地。USB 供电调试前先断开外部 5V。
