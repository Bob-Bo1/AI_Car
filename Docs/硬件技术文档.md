# AI 桌面小车硬件技术文档 V0.1

> 文档状态：硬件方案已完成，实物接线与电流测试待验收  
> 编制日期：2026-09-20  
> 适用主控：Seeed Studio XIAO ESP32-C3  
> 对应需求文档：`需求文档.md` V0.3  
> 安全提示：本文中的接线建立在用户提供的商品参数和官方资料上。升压模块最大电流、电池最大放电电流和驱动芯片丝印仍未确认，第一次总装前必须按第 7 节逐项测量。

## 1. 目标与边界

本文件负责确定 AI 桌面小车首版硬件方案，包括：

- 3.7V 单节电池、机械开关、5V 升压模块和整机供电路径；
- XIAO ESP32-C3 的最终 GPIO 分配；
- 双路 H 桥驱动板与两台 N20 电机的逐点连接；
- SSD1306 OLED、两颗 WS2812B 和电池检测电路；
- 去耦、抗干扰、USB 防反灌、装配和首次上电检查；
- 单模块和整机验收方法。

本版保持用户已经确认的路线：

- 两台电机为 12V、60 rpm、236:1 的 N20，使用 5V 驱动；
- 升压模块固定输出 5V，不需要控制信号；
- 主控和电机驱动共用 5V 主电源轨；
- 电脑和手机通过 Wi-Fi Web/PWA 控制；
- 电池电压检测保留。

本文件不能提前保证：实际续航、5V 下的电机转速和扭矩、升压模块带载能力、电池峰值放电能力。以上项目必须由实物测量确认。

## 2. 整机形态

### 2.1 硬件框图

```text
3.7V CR123A USB充电电池
        │
        ├── 电池电压分压 ──> XIAO D1 / GPIO3 ADC
        │
        └── SS12F44 电源开关
                 │
                 v
          3.7V -> 5V 升压模块
                 │
                 v
              +5V_BUS
        ┌────────┼───────────────┐
        │        │               │
        │        │               └──> 双路H桥 ──> 左右N20电机
        │        │
        │        └──> WS2812B电源 + 逻辑电平转换
        │
        └──> 肖特基二极管 ──> XIAO 5V
                                  │
                                  ├──> XIAO 3V3 ──> SSD1306 OLED
                                  └──> GPIO ──> 驱动板/OLED/前灯

所有模块 GND 共地
```

### 2.2 机械布局建议

- OLED 安装在正面窗口，排针朝车体内部，避免排线顶住外壳；
- 两颗 WS2812B 安装在正面左右灯位，第一颗靠近 XIAO 或电平转换器；
- 两台 N20 电机左右对称安装，输出轴和履带/轮胎不能相互蹭擦；
- 电机驱动板和 470–1000uF 滤波电容靠近电机，缩短大电流回路；
- XIAO 与电机驱动板保持距离，U.FL 天线和天线线缆远离电机、升压电感和大电流线；
- 电池 USB-C 充电口、XIAO USB-C 口、机械开关都应从外壳外侧可操作；
- 电池和线路必须固定，不能让电池外皮被螺丝、焊点或打印件锐边划伤；
- 电机线成对绞合，电源线与 I2C/WS2812B 数据线分开走线。

## 3. 功能定义

### 3.1 电机控制

驱动板使用 IN1/IN2 控制 MOTOR-A，IN3/IN4 控制 MOTOR-B。方案定义：

- MOTOR-A 接左电机；
- MOTOR-B 接右电机；
- 每个电机用两个 GPIO 控制；
- 运行时一侧输入 PWM，另一侧保持低电平；
- 停车默认使用 `00` 滑行/待机；紧急制动可短时使用 `11`，是否启用由实机冲击和电流测试决定；
- 电机正反方向与车体安装有关。首次测试发现方向相反时，只交换该电机的两根输出线，不修改公共电源极性。

| 目标动作 | IN1 | IN2 | IN3 | IN4 | 说明 |
| --- | --- | --- | --- | --- | --- |
| 停止 | 0 | 0 | 0 | 0 | 默认安全状态 |
| 前进 | PWM | 0 | PWM | 0 | 若某侧方向相反，交换该侧电机线 |
| 后退 | 0 | PWM | 0 | PWM | 换向前先减速到 0 |
| 左转 | 低速或 0 | 0 | PWM | 0 | 右轮速度高于左轮 |
| 右转 | PWM | 0 | 低速或 0 | 0 | 左轮速度高于右轮 |
| 原地左转 | 0 | PWM | PWM | 0 | 左轮后退、右轮前进 |
| 原地右转 | PWM | 0 | 0 | PWM | 左轮前进、右轮后退 |

### 3.2 OLED 显示

- 模块：0.96 英寸、128×64、SSD1306、I2C、四针；
- 电源：使用 XIAO 的 3V3 和 GND；
- 总线：D4/SDA、D5/SCL；
- 默认地址预计为 0x3C，正式烧录前运行 I2C 扫描程序；若扫描到 0x3D，则软件配置随实物修改；
- 模块通常自带 I2C 上拉电阻。未测量前不额外并联上拉，避免等效阻值过低。

### 3.3 两颗前灯

- 两颗 WS2812B 串联，共用 D10 一根数据线；
- 第一颗 DOUT 接第二颗 DIN；
- 每颗 VDD 与 VSS 之间就近放置 100nF 陶瓷电容；
- D10 到第一颗 DIN 串联 330Ω 电阻；
- 用户实物版本未确认。为兼容普通 5V WS2812B，正式方案增加 74AHCT1G125/74HCT125 电平转换，将 XIAO 的 3.3V 数据转换到 5V；
- 若实物确认是 WS2812B-V6，官方资料给出的高电平门限为 0.55×VDD，3.3V GPIO 在 5V 供电下可以满足；此时可在实测稳定后取消电平转换器，但第一版建议保留。

### 3.4 电池电压检测

电池满电电压按单节锂电池最高约 4.2V 设计。D1/GPIO3 使用 ADC1_CH3，避免 D3/GPIO5 的 ADC2 采样风险。

```text
SW_BAT+ ── R_TOP 100kΩ/1% ──┬──> XIAO D1 / GPIO3
                             │
                          R_BOTTOM 100kΩ/1%
                             │
                            GND

D1/GPIO3 ── C_ADC 100nF ── GND
```

- 分压比为 1:2，电池 4.2V 时 ADC 节点约为 2.1V；
- 分压静态电流约 21uA；
- 软件初始换算为 `VBAT = VADC × 2`，再用万用表做两点标定；
- 目标误差为 ±0.10V；
- 检测点接在开关后的 `SW_BAT+`，整车关闭后分压电阻不继续耗电。

### 4.3 条件性保护器件

现有 SS12F44 系列开关的公开规格存在 0.5A/50V 与 1A/24V 等不同厂家版本。开关位于电池输入侧时，实际电流高于 5V 负载电流按电压比折算后的结果。

- 已核实手中开关额定电流至少为1A、实测整车峰值电池电流不超过0.8A，且开关连续运行不发热：可以让开关直接串联在电池正极；
- 峰值超过 0.8A、开关发热、触点压降明显：增加 AO3401A/IRLML6402 一类 P 沟道 MOSFET 高侧开关，让 SS12F44 只控制 MOSFET 栅极；
- 无法核实开关额定电流：默认采用P沟道MOSFET高侧开关；
- 若不方便焊接 MOSFET，直接更换额定 2A 以上的小型机械开关更简单。

P-MOS 方案连接原则：电池正极接 MOSFET Source，MOSFET Drain 接升压输入正极；Gate 用 100kΩ 上拉到 Source，滑动开关把 Gate 接到 GND 时开机。具体封装引脚必须按所购 MOSFET 规格书核对。

### 6.2 开关三脚判定

SS12F44 是 1P2T 三脚开关。常见结构为中间脚 COM，拨向哪一侧就接通该侧外脚，但不能只根据照片判断左右哪边是 ON。

装配前用万用表蜂鸣档确认：

1. 找出始终作为公共端的中间脚；
2. 拨到预定 ON 方向，测出与中间脚导通的外脚；
3. 电池正极接中间 COM，ON 外脚接升压 VIN+；另一个外脚悬空并做好绝缘；
4. 如果外壳标识方向与测量结果相反，以万用表结果为准；
5. 测量整车峰值电池电流后，再决定是否增加 P-MOS 高侧开关。

### 6.3 共地与星形回流

所有 GND 必须电气相连，但大电流回流应按星形布线：

```text
升压 VOUT-
  ├── 粗线到驱动板 GND
  ├── 独立线到 XIAO GND
  ├── 独立线到 OLED/WS2812B/电平转换 GND
  └── 电池检测 R_BOTTOM/C_ADC GND
```

不要让电机电流先经过 XIAO 的 GND 焊盘再回到升压模块。这样会把电机压降和噪声叠加到主控地线上。

### 6.4 功耗与电流预算

| 负载 | 估算/已知 | 设计取值 | 说明 |
| --- | --- | ---: | --- |
| XIAO ESP32-C3 Wi-Fi活动 | Seeed资料约75mA | 150mA峰值裕量 | Wi-Fi瞬态需留余量 |
| OLED | 未提供模块电流 | 30mA | 与亮度和画面有关 |
| 两颗WS2812B | 版本不明 | 120mA最坏值 | 按普通RGB三通道全亮保守估算 |
| 驱动逻辑 | 未提供 | 20mA预留 | 不含电机 |
| 两台N20 | 完全待测 | 暂不填固定值 | 必测5V空载、起步、短时堵转电流 |

在电机数据缺失时，升压模块建议按 5V/2A 连续、5V/3A 短时峰值选型。若模块达不到此指标，必须通过实测证明现有负载不会让 5V_BUS 低于 4.75V，也不会使 XIAO 重启。

电池标称能量为 1850mWh。升压后的理想可用能量还要乘以升压效率，实际续航公式为：

`续航小时 ≈ 1.85Wh × 升压效率 ÷ 5V侧平均功率`

由于电池最大放电电流未知，这个公式只能用于测量后的估算，不能证明电池能承受启动峰值。

## 7. 结构、装配与首次上电检查

### 7.1 装配顺序

1. 用卡尺测量 XIAO、驱动板、升压模块、电池、OLED 和开关，先核对打印件空间；
2. 单独焊好电池分压、电机抑制电容、驱动板入口电容和LED去耦；
3. 不接电机，完成XIAO、OLED和两颗前灯的低功率联调；
4. 单独给驱动板供5V，用一个电机逐路验证IN1–IN4；
5. 测量两台电机5V空载电流和短时堵转电流；
6. 核对升压模块与电池能力后，再合并电源；
7. 固定电池和线束，最后安装履带/轮胎并做离地测试；
8. 落地后从最低PWM开始标定左右电机。

### 7.2 分模块验收

| 模块 | 测试方法 | 通过标准 | 失败处理 |
| --- | --- | --- | --- |
| 电池 | 万用表测正负极和静置电压 | 极性正确，电压处于单节锂电合理范围 | 停止连接，核对电池保护和电量 |
| 开关 | 蜂鸣档判定COM与ON脚 | OFF断路，ON接触稳定 | 更换或重焊 |
| 升压 | 先不接负载，测VOUT；再接电子负载或功率电阻 | 空载与带载均在5.0V附近，无异常发热 | 不接主控和电机，换模块 |
| XIAO | 经SS34从外部5V供电 | 能正常启动和连接Wi-Fi，5V/3V3无异常 | 检查二极管方向和电源压降 |
| OLED | I2C扫描 | 扫到0x3C或0x3D，画面稳定 | 检查SDA/SCL、供电和地址焊盘 |
| WS2812B | 低亮度红绿蓝测试 | 两颗顺序和颜色正确，无随机闪烁 | 检查缺口方向、DIN/DOUT、去耦和电平转换 |
| 驱动A/B | 不装轮，单路低PWM测试 | 四个输入按真值表控制对应电机 | 核对输入和输出端 |
| 电池检测 | 同时读取ADC和万用表 | 标定后误差≤±0.10V | 调整校准系数和采样滤波 |

### 7.3 首次上电检查表

上电前：

- [ ] 电池正负极、升压输入正负极、5V输出正负极全部核对；
- [ ] SS12F44 的 COM 与 ON 脚已经用万用表确认；
- [ ] SS34 阳极接 5V_BUS，阴极接 XIAO 5V；
- [ ] 驱动板、XIAO、OLED、LED和ADC分压共地；
- [ ] 驱动板入口有470–1000uF与100nF电容；
- [ ] 每台电机端子间已焊100nF电容；
- [ ] 每颗WS2812B的1/2/3/4脚已按VDD/DOUT/VSS/DIN核对；
- [ ] D0、D8、D9没有接外设；
- [ ] 两个电机悬空离地，履带/轮胎能自由转动；
- [ ] XIAO USB-C暂不连接电脑，或整车开关保持OFF；
- [ ] 电源限流设定合理，手边可以立即断电。

上电顺序：

1. 暂不连接XIAO和电机，先测升压输出，调整或确认5.0V；
2. 关闭电源，连接XIAO支路，保持驱动板与电机断开；
3. 上电确认XIAO启动、3V3正常、OLED和前灯工作；
4. 断电，连接驱动板但暂不接电机，确认IN1–IN4上电为低；
5. 断电，先接一台电机，低PWM测试；通过后再接第二台；
6. 两台电机离地同时缓慢启动，监测5V_BUS最低电压、电池电流和器件温升；
7. 全部通过后再落地测试。

立即断电条件：

- 5V_BUS 空载高于5.25V或低于4.75V；
- XIAO反复重启、Wi-Fi频繁掉线或OLED随机熄灭；
- 电池、升压模块、开关、驱动板或导线快速发热；
- 出现焦味、异响、冒烟、火花或电机长时间堵转；
- 电池电压在起步瞬间明显塌陷并触发保护；
- 驱动板输出与输入真值表不符。

### 7.4 USB调试规则

- 推荐整车开关OFF时连接XIAO USB-C烧录和查看日志；
- SS34可阻止USB 5V从XIAO 5V脚反灌到整车5V_BUS；
- 首次调试不要同时让电脑USB和未验证的升压模块给XIAO供电；
- 若需要开机同时看串口，先确认SS34方向、两侧电压和没有反向电流；
- 电池使用自身USB-C充电时，整车开关保持OFF。电池资料没有确认边充边用能力。

## 9. 关键风险与决策

| 编号 | 风险/决策 | 影响 | 当前处理 |
| --- | --- | --- | --- |
| R1 | 12V电机以5V驱动 | 速度和扭矩低于标称值，左右差异未知 | 用户已确认；逐台测最低启动PWM和电流 |
| R2 | 电池只有约500mAh，放电能力未知 | 启动时可能保护关断或电压塌陷 | 总装前测峰值电池电流；异常则更换电池 |
| R3 | 升压模块型号与额定电流未知 | 可能造成5V下跌和主控重启 | 要求5V/2A连续、3A峰值或用实测证明足够 |
| R4 | SS12F44厂家版本额定值不同 | 触点发热、压降或寿命降低 | 峰值>0.8A时使用P-MOS或换≥2A开关 |
| R5 | 驱动板商品标题混用“L298N” | 错用芯片资料会导致接线和控制错误 | 按用户提供的四输入真值表设计，继续核实丝印 |
| R6 | 电机噪声进入主控电源 | Wi-Fi掉线、ADC波动、XIAO重启 | 星形地、粗电源线、驱动入口大电容、电机端100nF |
