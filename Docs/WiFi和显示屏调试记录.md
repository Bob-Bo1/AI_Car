# WiFi和显示屏调试记录

日期：2026-10-16。

## 硬件与范围

- 实际识别：ESP32-C3，芯片修订v0.4，4MB闪存，USB串口COM6。
- 用户确认：XIAO ESP32-C3、SSD1306，3V3供电，SDA接D4，SCL接D5。
- 本轮只调试WiFi和屏幕，电机控制脚保持低电平。

## 已通过

- 原固件完整备份4194304字节，并生成SHA256，位于 `firmware/backup/`。
- 测试固件编译成功，烧录后工具对写入数据进行哈希校验并通过。
- 实机I2C扫描找到0x3C。
- 屏幕初始化返回ESP_OK，连续刷新返回ESP_OK。
- USB串口STATUS指令能够返回状态。
- 用户现场确认：完整显示边框、两眼和嘴，周期反色正常。
- 本地提交WiFi配置，模组获取IP：192.0.2.20。
- 电脑访问 `http://192.0.2.20/`，返回wifi=connected、oled_detected=true。
- 电脑发送3次ping，3次收到回复，丢包0%，延迟74–94ms。
- 用户点击重启；日志记录新的BOOT和OLED_INIT成功，约1秒后自动重新获取192.0.2.20。
- 重启后再次访问状态页成功，用户确认屏幕恢复正常。

## 验收边界

本轮通过USB供电下的软件重启验证；尚未进行拔电后重新上电、长时间运行和电机工作时的干扰测试。
