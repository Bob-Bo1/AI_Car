# Web控制台联调记录

日期：2026-10-22。主控XIAO ESP32-C3，ESP-IDF 5.5.4，固件v0.3.0。

## 本轮目标和结论

目标：小车自己提供网页，沿用当前Wi-Fi，支持A/B电机测试和前后左右控制；拔掉USB、保留独立供电后仍可操作，并能在指令停止或连接断开时关闭输出。

结论：本轮目标通过。用户确认独立供电已接好、轮子架空；最后拔掉USB后，A反转和两个电机同转均正常转动并停下，屏幕正常。电脑串口列表中无COM6时，小车仍在192.0.2.20回传联网、屏幕与停车状态。

用户明确暂不确定A/B安装左右，因此本轮只验收方向按钮对应的电气输出组合，不将其当作车身方向已经校准。

## 实现

- 单文件HTML/CSS/JS嵌入固件，由小车HTTP服务直接提供，浏览器使用WebSocket控制；没有电脑后台和USB转发依赖。
- 单电机A/B正反转，0.3秒或2秒硬截止；网页需持续续期，失联可提前停车。
- 前后左右按住运动，松开停车；方向键、WASD和空格操作。
- 50%至100%输出调节；默认100%延续已验证启动条件，尚未标定低速。
- 固件电机任务每10ms检查，450ms无有效运动更新即关闭PWM；常规连接心跳不能续期旧行驶指令。
- 反向先写零，再等待100ms；A/B反向与左右轮交换可停车后保存，NVS写入后回读。
- 单连接控制权、会话令牌和递增序号；页面刷新或重连不自动恢复控制/动作。
- 急停锁定与主动解锁；Wi-Fi状态、IP、RSSI、OLED、目标及输出百分比、停止原因显示。
- Wi-Fi沿用电脑当前连接，Windows WLAN配置仅在内存读取并经USB提交；密码未写入项目、日志或聊天。最终重启后自动回连，OLED底部显示IP。

## 验证结果

| 检查 | 结果与边界 |
| --- | --- |
| 编译及烧录 | 最终构建通过，烧录哈希校验通过，应用镜像929920字节 |
| Wi-Fi保存与重启 | 写入最终固件并重启后自动连接已保存网络，HTTP/WS恢复；主控彻底断电及路由器恢复场景未单独完成 |
| 页面初始状态 | 查看模式，方向/测试按钮禁用；需领取控制权并确认安全放置 |
| 单控制端 | 同一电脑两个独立WebSocket客户端争用，第二端被拒；真实电脑＋手机争用未测 |
| 指令校验 | 无控制权、无效电机、方向0、时长1999ms、输出101或50.5、未知动作、重复序号均被拒绝且不启动 |
| 急停 | 急停后锁定，旧控制权取消；重新领取并主动解锁后恢复待机，锁定期间运动被拒 |
| 网页单电机 | A正转与B反转2秒由网页按钮触发；用户分别确认转动和屏幕正常，B确认自动停下；A测试结束由状态确认 |
| 双电机 | 通过Wi-Fi同时转2秒，用户确认都转动并停下、屏幕正常 |
| 四方向输出 | 前进(+255,+255)，后退(-255,-255)，左转(-255,+255)，右转(+255,-255)，各次停止后两路回零；真实左右安装映射留待装车 |
| 网页键盘 | 最终版本W/S/A/D分别按住1秒并松开；观察到对应输出组合，停车后两路归零 |
| 指令中断 | WebSocket保持连接但停止运动续期，小车记录448ms后PWM写零，原会话后续运动被拒，需重新取得控制权 |
| 连接关闭 | 关闭控制连接，小车记录最后运动更新后443ms PWM写零，取消控制权 |
| 手机布局 | 浏览器375px宽时无横向溢出，方向按钮约90×78px；未代替真实手机触控与后台测试 |
| 拔USB状态 | 用户确认USB已拔、屏幕仍亮；Windows只有COM4/COM5蓝牙串口，无COM6；Wi-Fi状态持续正常 |
| 拔USB实际操作 | 通过网页A反转2秒，再W键保持2秒让两台电机同转；用户确认均正常转动并停下、屏幕正常 |
| 最终状态 | 已停车，输出A/B均为0，控制权已释放；浏览器保留查看页面 |

停车计时取自设备内部：最后一次有效运动更新至LEDC关闭输出调用成功后的时间。主机收到状态的时间分别约702ms、590ms，其中包含网络/轮询延迟，不能直接用作输出关闭耗时。上述结果也不替代示波器信号测量或机械惯性停车时间测量。

## 未完成范围

本轮未完成真实左右安装校准、落地行驶、最低启动PWM、稳定低速、20次启停/换向、真实手机、路由器断电恢复、电气波形、电流/温升及15分钟连续遥控验收。Wi-Fi已联网时可在页面更换配置；完全离线时仍需USB本地窗口，本版没有SoftAP热点兜底。灯光、电池检测、摄像头和AI功能未接入。
