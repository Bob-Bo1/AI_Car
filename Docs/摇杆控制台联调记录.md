# 摇杆控制台联调记录

日期：2026-10-23。固件v0.3.1，XIAO ESP32-C3，ESP-IDF 5.5.4。

## 改动

- 驾驶区替换为圆形摇杆，支持连续方向、弧线差速、左右原地转向和按幅度调节输出；双轮小车无法横向平移。
- 摇杆中心8%死区，松手、触摸取消、丢失捕获和页面失焦时停车。键盘可组合方向，松开一个键后保留另一个方向；摇杆与键盘互斥。
- 新增整车前后互换设置，只改变驾驶的前后量；原有A/B测试、各电机反向及左右轮交换保持独立。保留旧版四方向WebSocket指令兼容。
- 设置写入NVS并回读；本次保存A反向=true、B反向=false、左右交换=false、整车前后互换=true。最终固件再次写入并重启后，四项设置保持一致。
- Wi-Fi继续使用已保存的LEO欢乐屋热点，无密码或网络修改。重启分配地址为192.168.137.41，已更新本地打开入口和浏览器。

## 验证

用户确认轮子已架空、USB已连接后进行短转。

| 项目 | 结果 |
| --- | --- |
| 编译与写入 | 最终镜像933120字节，构建通过，烧录哈希验证通过 |
| 实际页面脚本测试 | 中心死区、超出圆周限幅、幅度计算、松手/取消/捕获丢失、组合键及部分松键、失去控制权、急停、失焦和方向设置通过 |
| 实机九组方向 | 前后、左右、四个斜向及前后100/转向50的目标与PWM输出符合预期；每次停车后两路归零 |
| 输出上限 | 50%上限对应目标幅度127，参数越界、缺少轴及小数/布尔输入拒绝 |
| 中心停车 | 运动后发送前后0/转向0，两路输出关闭 |
| 运动超时 | 保留普通状态心跳，但停止发送运动指令，设备444ms关闭输出并取消原控制权 |
| 连接关闭 | 关闭运动连接，设备记录217ms后输出归零 |
| 最终网页操作 | 鼠标摇杆向前、斜向及W键保持并释放；独立HTTP采集95条状态，含20条运动状态，最终目标和PWM输出均为0 |
| 重启保存 | 最终重新烧录后读取reverse_drive=true，原有A/B校准保留，上电待机两路为0 |
| 用户实物确认 | 用户确认“转动、停车和屏幕正常，前进方向也对” |
| 收尾 | 自动检查结束时已停车并释放控制权；随后用户自行领取验证，页面保留供用户操作 |

设备停车计时取自最后有效运动更新至LEDC关闭输出调用成功，不代表机械惯性停车时间。连续差速通过电气输出检查；真实左右安装、落地转弯、低速稳定性及长时间带载仍需进一步调试。本轮未改动供电与Wi-Fi逻辑，未要求再次拔USB验证。
