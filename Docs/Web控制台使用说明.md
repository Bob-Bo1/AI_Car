# 小车Web控制台

小车提供独立的Wi-Fi控制页面；电脑另提供固定工作台入口，自动发现这台小车，IP变化后自动重新匹配。

## 打开和连接

1. 给主控、驱动和电机接好独立电源，小车自动连接已保存的2.4GHz Wi-Fi。
2. 电脑与小车接入同一局域网或电脑热点，双击项目根目录“打开小车控制台.cmd”。脚本会自动启动本机后台，打开固定入口 **http://127.0.0.1:8876/**。
3. 等待显示“Wi-Fi已连接”，连接后即可拖动摇杆，首次主动操作会申请接管。

工作台按固定设备身份广播寻找小车，旧IP失效时持续重新发现并匹配新IP，无需手动填写。小车离线时保留页面等待，上线后恢复查看；重新操作会申请接管，之前的动作不会恢复。固定电脑入口需要本机后台运行；电脑重启后再次双击入口即可。

自动发现要求局域网允许设备间通信及UDP广播，不保证跨网、访客隔离网络或互联网连接。手机可接入同一网络，使用工作台“小车地址”显示的IP访问小车页面；手机上的127.0.0.1指向手机自身。USB可拔掉，但主控和驱动需要独立供电。

## 电机测试

- A/B各有正转、反转测试按钮。
- 可选2秒或0.3秒，一次只测试一台电机。
- 固件到时自动关闭输出；网页离开、连接断开或不再发送测试续期，也会提前停止。
- 测试后检查电机是否实际转动并停下、屏幕是否正常，再进行下一项。
- 输出百分比及正负号代表PWM输出和电气方向，不代表测得的转速。

## 摇杆驾驶（v0.3.1）

连接后按住拖动浅灰圆形摇杆。向上前进、向下后退，斜推可转弯，横推左右可原地转向；推得越远，输出越大。两轮差速小车无法横向平移。松手、触摸取消或摇杆回到中心会停车，中心8%范围不发送运动输出。

电脑支持方向键、WASD，可同时按两个方向，如W+D向右前方转弯；松开其中一个键后保留另一方向，全部松开停车。空格也能停车。输入Wi-Fi名称和密码时不响应方向键。拖动摇杆后可以直接接着用键盘；键盘控制期间不同时接收触摸操作。

本次根据安装调整，已保存“整车前后互换”：前进和后退相对上一版对调，左右原地转向和A/B单电机测试定义保持原样。当前设置为A反向开启、B反向关闭、A/B左右轮交换关闭、整车前后互换开启。停车后可在“方向校准与Wi-Fi设置”中修改，断电保留。实际左右轮安装仍需观察校准。

设置面板中的滑块设置最大输出，默认100%，范围50%至100%；摇杆幅度在这个上限内连续调节两侧输出。固件按前后量与转向量计算两轮差速，超出最大输出时同比缩小。小幅推杆可能无法持续起转，最低启动输出和实际车速仍未标定。行驶保留100ms启动辅助、输出变化限制和100ms换向等待。

## 停车保护

- 松手、摇杆回中或空格为普通停车。
- 驾驶区移除手动控制权、安全勾选和急停按钮；设备若已锁定，只在锁定时显示解除入口，故障锁定不能直接解除。
- 小车独立检查网络运动指令，450ms无有效更新即关闭输出；实现目标包含调度余量，要求在500ms内停止有效驱动。
- 正常心跳仅保留控制权，不延长旧的行驶指令。
- 网络恢复、网页刷新、重新连接均不自动恢复运动，重新操作即可接管。
- 同时只有一个浏览器连接可控制，另一设备只能查看；v0.6.0支持主动操作接管：新设备操作时停止旧动作并接管，旧设备必须松手后重新操作，心跳不抢占。
- 参数越界、重复序号、无控制权的运动请求均被拒绝。

## Wi-Fi设置

日常使用无需重新填写。更换网络时，在停车状态下，在设置中填写新的2.4GHz Wi-Fi名称与密码并保存。切换期间会停车和断开网页，电脑固定工作台会持续寻找新地址；需要新网络允许电脑与小车互通。

密码输入框提交后清空；不回传密码，不打印密码，不写入电脑项目文件。网页配网需要已有局域网连接；本版未实现小车热点配网，完全无法联网时可接回USB使用已有本地配网窗口。

## 当前边界

- 独立供电必须同时覆盖主控与电机驱动，网页无法代替供电。
- 左右轮实际安装方向由用户后续校准，当前不承诺实际车身前后、转弯方向已校准。
- 电池电压、灯光、摄像头、自动驾驶暂未接入。
- 本版用于局域网，不配置公网转发。
- 单次短测与网页通信通过，不等于已完成低速、长时间、带载、温升和整车稳定性验收。

## 屏幕表情（v0.5.0）

当前采用实心圆角方眼：转弯时两眼向对应方向移动，最大7像素；前进时略睁大、后退时稍收小。正常待机自然眨眼，60秒闲置后困倦，90秒后视觉睡眠。睡眠期间Wi-Fi保持连接，领取控制权或操作即可唤醒。页面“屏幕”栏可查看当前表情和刷新健康。表情表示驾驶指令，不代表测得的实际车身方向。

屏幕只保留眼睛，不显示联网图标、状态文字或IP。这些信息可在工作台查看。

2026-10-23简约驾驶区：浅灰圆盘和四个方向点，操作说明仅“按住拖动，松手停车。支持方向键 / WASD。”；最大输出移至折叠设置。本次更新电脑固定工作台页面，无需重新烧录；小车固件内置页面需下次烧录才能同步。自动申请控制权不发送运动、不解除锁定、不恢复旧输入。

## v0.6.0 首次使用与无线升级

小车自带AI-Car热点（后缀和密码见刷写工具生成的本机连接信息），手机/电脑连接后用系统浏览器打开 http://192.168.4.1/ 。无需电脑后台。也可在设置中保存家里2.4GHz Wi-Fi，热点仍保留作为固定入口。手机直接使用小车内置的最新版简约摇杆。

本机工作台仍为 http://127.0.0.1:8876/ ，只用于这台电脑。无线升级请打开小车实际IP页面或热点页面，展开“固件无线升级”，仅上传配套ai_car_bench.bin。首次双分区迁移需要USB；以后应用升级可用Wi-Fi。升级前停车，升级期间保持稳定供电，成功后重启并刷新。

双分区各1.5MiB；原NVS地址和大小保持不变。未经校验或中断上传不切换程序区；新程序启动确认前重启可回退，不能承诺所有运行期故障均自动回退。
