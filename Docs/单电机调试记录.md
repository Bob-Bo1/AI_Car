# 单电机A调试记录

更新日期：2026-10-21。

## 目标与范围

用户当前只有一个电机，已接MOTOR-A和驱动IN1/IN2。2026-10-21用户确认实物规格为6V、50转/分钟。本轮验证该电机能否正转、停车、反转；不开展双电机、差速或落地行驶。

计划控制引脚：IN1→XIAO D2/GPIO4，IN2→D3/GPIO5；IN3/IN4对应主控GPIO21/20继续保持低电平。

## 程序

- 固件增加 `firmware/main/motor_bench.c`，LEDC为20kHz、8bit。
- 上电和重启后默认停车，不自动转动；仅USB串口接受单电机测试指令，HTTP保持只读。
- 转动期间另一输入保持低，禁止两个输入同时输出PWM。
- 普通PWM缓升指令限制最多1000ms、占空比128/255；空载测量模式为128/255、8000ms，必须断开电机。专用启动测试固定255/255、300ms，不缓升，本地窗口使用已验证的启动测试。
- 运行中或停车后100ms内拒绝新的转动请求；停止指令优先覆盖待处理请求。
- 专门的电机任务负责超时停车，不等待OLED刷新；窗口关闭时尝试发送STOP，断开窗口仍由固件到时停止。
- 本地入口：项目根目录 `打开单电机测试.cmd`；测试日志 `firmware/motor-bench-log.txt`。

串口命令：`MOTOR FWD 64 500`、`MOTOR REV 64 500`、`STOP`、`STATUS`。FWD/REV仅代表两个电气方向，需观察实际安装方向。

## 实机验收顺序

1. 烧录后只查询状态：确认MOTOR_READY、motor=stopped，轴不转。
2. 验证非法参数被拒绝，且不出现MOTOR_START。
3. 以25%占空比正转500ms，观察能否起转，以及结束后是否停车；如只响不转，停止后再分析，不连续重复。
4. 确认无异常发热和复位，再以相同参数反转500ms，观察方向是否相反。
5. 核对日志中启动和自动停车事件；同时检查WiFi、HTTP和OLED是否正常。

日志只能证明固件执行指令及关闭输出；电机实际转动、方向、停止和温升需要现场确认。该测试不代替最低启动PWM标定、20次启停/换向、电流测试及完整失联保护验收。
